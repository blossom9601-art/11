무결성 정책

중요 파일, 설정, 계정, 서비스 변경을 추적하는 File Integrity Monitoring 정책을 관리합니다.

감시 대상

기본 10분 주기로 SHA256, 권한, 소유자, 그룹, 크기, 수정시간을 비교합니다.

Linux 계정/인증/etc/passwd, /etc/shadow, /etc/group, /etc/sudoers, /etc/pam.d/*
SSH / 스케줄러/etc/ssh/*, /root/.ssh/*, /home/*/.ssh/*, /etc/crontab, /etc/cron.d/*
네트워크 / 서비스/etc/hosts, /etc/resolv.conf, /etc/systemd/system/*, /usr/lib/systemd/system/*
Windows 핵심 영역GroupPolicy, Services, Run, Tasks, RDP, Firewall, PowerShell

위험도 / KPI

상세 페이지 분석 모달에서 동일 기준으로 Critical, High, Medium, Low를 시각화합니다.

Criticalpasswd, shadow, sudoers, PAM, SSH, GroupPolicy, Services
HighCron, Task Scheduler, Firewall, RDP, PowerShell
MediumNetwork, rsyslog, auditd 설정
Low일반 설정 파일
변경 유형표시 기준상세 분석
신규새 파일 생성생성자, PID, 프로세스, 접속 IP
수정SHA256 또는 수정시간 변경Diff Viewer, 변경 전/후 비교
삭제기준 파일 미존재삭제 시각, 감사 로그 연계
권한/소유자 변경Permission, Owner, Group 변경영향 서비스 자동 분석
