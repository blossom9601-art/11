로드맵 요약 (Phase 1~4)
  1. 역할 분리: Blossom은 권한·프로세스·접속 기록, 실제 URL·네트워크 통제는 프록시/ZTNA/SWG와 병행.
  2. 호스트 게이트: 아래 패턴을 채우면, 패턴에 맞는 호스트만 WEB 접속이 진행됩니다.
  3. iframe 모드: 허용 호스트에 한해 이 페이지 안에 임베드(대상이 iframe을 막으면 표시 안 됨).
  4. 감사: 상세 클릭 로그는 게이트 로그와 함께 보는 것을 권장.
