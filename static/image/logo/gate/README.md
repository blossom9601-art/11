# Lumina-Gate Reference-Based Icon Assets

These assets were extracted from the provided reference image, using the center shield/globe/lock icon and removing the surrounding wallpaper, labels, and icon-set text.

- `lumina-gate-reference-icon-transparent.png`: transparent master PNG.
- `lumina-gate-reference-preview.png`: preview on dark and light backgrounds.
- `png/`: common PNG sizes from 16px to 1024px.
- `windows/lumina-gate-reference.ico`: multi-size Windows icon.
- `macos/LuminaGateReference.iconset/`: macOS iconset source folder. Convert on macOS with:

```bash
iconutil -c icns LuminaGateReference.iconset
```
